# DCO Study Lab

A free static interview-preparation workspace for data center operations technician roles. Built for GitHub Pages with no build step or backend.

## Features

- Eight detailed learning modules and a dated weekday study plan
- Topic quizzes with explanations and latest-answer breakdowns
- Flashcards and a review pile
- Troubleshooting scenarios, checkpoints, notes, and follow-up prompts
- STAR story builder and a three-round mock interview mode
- Focus timer, full-text lesson search, printable lessons
- Browser-local progress, JSON export/import, and reset controls
- Responsive layouts and keyboard navigation

## Run locally

Serve this directory using any static HTTP server, such as `python -m http.server 8000`, then open `http://localhost:8000`. No package installation is required.

## Publish with GitHub Pages

In repository Settings → Pages, choose Deploy from a branch, select `main`, and use `/ (root)`. The `.nojekyll` file makes this a plain static deployment. Asset paths are relative, and navigation uses hashes, so project Pages URLs are supported.

## Privacy

Lessons and practice material are public. User-entered stories, notes, and progress are stored only in that browser's local storage under `dco-study-lab-v1`. There is no analytics or application backend. Optional Google Fonts requests load typography; system-font fallbacks are provided. JSON backups are unencrypted and contain entered notes. Imported backups replace this app's local progress after confirmation.

## Educational scope

Independent preparation, not affiliated with Amazon. Original practice questions and self-assessment rubrics are not official interview questions or hiring criteria. Resources and role-derived recommendations were reviewed October 7, 2026. Follow the recruiting team's current instructions and approved procedures in real environments.
